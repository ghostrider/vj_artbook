# 1000a — VJ Art Book

A living book of visual ideas for live audiovisual performance. It grows every week.

Each chapter takes one idea from the wider world of art, science, nature or code
and follows it all the way to the stage:

- **Origin**: where the idea comes from, who has worked with it
- **Visual language**: what it looks like, how it moves, how it can react to sound
- **In code**: a runnable ISF/GLSL shader for Resolume, plus notes for Wire and Unreal
- **On stage**: how to play it live with MIDI, BPM and layering
